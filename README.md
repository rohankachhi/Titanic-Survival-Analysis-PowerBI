# Titanic Data Analysis Dashboard – Power BI

## Project Overview

This project focuses on analyzing the Titanic passenger dataset to understand passenger demographics, survival rates, and key factors that influenced survival. An interactive Power BI dashboard was developed to explore passenger information and identify meaningful patterns through data visualization.

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- DAX
- Data Cleaning & Transformation
- Data Visualization

## Key Features

- Total passengers and survival rate analysis
- Male vs. female survival comparison
- Passenger class-wise survival analysis
- Age group and passenger demographics analysis
- Embarkation point analysis
- Interactive charts, filters, and KPI cards

## Project Files

- Titanic Dataset
- Cleaned Dataset
- Power BI Dashboard (.pbix)
- Dashboard Screenshots

## Key Learnings

- Data cleaning and preprocessing
- Handling missing values
- Data transformation
- DAX calculations and KPI development
- Interactive dashboard creation
- Exploratory data analysis and insight generation

## Project Outcome

Developed an interactive Power BI dashboard to explore Titanic passenger data, analyze survival patterns, and understand how factors such as gender, age, and passenger class relate to survival.
